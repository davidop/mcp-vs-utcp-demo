# Release v1.0 acceptance gates

- [ ] Official SDK versions locked and installed in clean CI.
- [ ] Product, stock and order operations have equivalent parameter schemas and responses.
- [ ] Invalid SKU, malformed input and duplicate order tests pass.
- [ ] Warm and cold benchmarks record actual raw samples, errors and environment.
- [ ] Connection pooling and transport differences documented; repeated alternating runs completed.
- [ ] Dashboard imports actual CI output and Pages deployment succeeds.
- [ ] Official logos sourced and usage terms documented.
- [ ] Slidev builds successfully.
- [ ] Microsoft Agent Framework example runs; Azure integrations labeled as verified or conceptual.
- [ ] English and Spanish documentation reviewed.
- [ ] License and contribution guide present.
- [ ] Release tag points to passing commit and links evidence.

No checkbox may be marked complete solely because source code exists.
